# 📝 Primeiro Projeto – Cálculo de Média
Este projeto em Python foi criado para praticar o ciclo **Entrada → Processamento →
Saída**.
O programa solicita o **nome do aparelho, sua potência e o tempo médio de uso diário**, calcula o **consumo mensal e o custo estimado**, e mostra os resultados juntamente com a **classificação do nível de consumo**.
